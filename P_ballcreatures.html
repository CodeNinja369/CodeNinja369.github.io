Ball Creatures

This project uses sfml to simulate creatures that eat eachother

Overview:

a ball class stores the details of each creature as an object. This ball class is used to keep track of the ball's different attributes, as well as to control it's behaviour/movement

Find Repository At:

https://github.com/CodeNinja369/BallSim
balls.cpp

generates vector of balls at slightly random positions, at random sizes within size range, and random colours. Creates window and main simulation loop. Handles ball death, ball attacks and ball collision

ball.h

Header that defines the ball class, with all members outlined including public functions and private variables

ball.cpp

initialises all members of ball class

ball class private members

sf::Vector2<float> pos -- position of the ball

sf::CircleShape circle -- sfml CircleShape object that keeps track of what is drawn to the screen to represent the ball

int size -- radius of the ball

float speed -- how many pixels the ball moves per update

sf::Color colour -- sfml Color object that represents the colour of the circle

bool dead -- keeps track of whether the ball is dead

int dmg -- how much damage the ball does to another ball on collision

int health -- health of a ball

void updateCircle() -- private helper function that updates the CircleShape each time a change is made to the ball's attributes

int internaltick -- keeps track of a ball's cooldown for damage

float finddist(sf::Vector2<float> ppp, sf::Vector2<float> ttt) -- private helper function that finds the distance between two sfml float vector2s

ball class public members

ball(sf::Vector2<float> p, int s, float sp, int d, sf::Color c)-- constructor

>sf::Vector2<float> getPos() -- returns pos

sf::CircleShape getCircle() -- returns circle

int getSize() -- returns size

int getDMG() -- returns damage

int getHealth() -- returns health

void attack(std::vector<ball*> target) -- moves ball speed pixels towards another ball

ball* findTarget(std::vector<ball*> bs) -- finds closest ball to ball

bool isDead() -- returns dead

void die() -- sets dead to true

void damage(int d) -- lowers health by d

void collide(ball* b2, int t) -- checks collision between balls, moves them based on collision, damages balls collided based on t (which represents the external tick)
